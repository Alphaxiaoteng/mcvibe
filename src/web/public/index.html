📋 3 步轻松获取你的官方 Token：
1
访问麦当劳开放平台
电脑或手机浏览器打开 open.mcd.cn/mcp，使用手机号/微信登录。
2
进入控制台激活 Token
点击页面右上角【控制台】→ 点击【激活】申请个人 MCP 凭证，一键复制生成的 Bearer Token。
3
粘贴并点亮足迹
点击右上角【⚙️ 设置】粘贴 Token，保存即可瞬间拉取真实点餐记录！
